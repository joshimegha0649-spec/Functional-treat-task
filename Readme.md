# Data Analyzer and Transformer Program

## Project Description
The Data Analyzer and Transformer Program is a menu-driven Python application that allows users to enter a list on numbers and perform different operations on the data. It uses Python built-in functions,recursion, lambda functions, sorting, and multiple return values.

## Features
 Input Data -- Enter numbers separated by spaces and store them in a list.

 Display Data Summary -- Show the total number of elements,minimum value, maximum value, sum, and average.

 Calculate Factorial -- Calculate the factorial of a number using recursion.

 Filter Data by Threshold -- Display values greater than or equal to a threshold using a lambda function.

 Sort Data -- Sort the entered numbers in ascending or descending order.

 Display Dataset Statistics -- Return and display the minimum, maximum, sum, and average values.

 Exit Program -- Close the program.

## Concepts Used
 Python lists
 User input and output
 Built-in functions: len(), min(), max(), and sum()
 Functions
 Recursion
 Lambda functions
 Sorting with sort()
 Multiple return values
 while loop and conditional statements
